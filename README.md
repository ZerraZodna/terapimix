# Live Terapimix – Webprosjekt

## Oversikt
- Statisk webside for Live Sørlie / Terapimix
- Spirituell terapi og veiledning
- Ingen backend nødvendig – ren HTML/CSS/JS
- Enkelt å hoste (GitHub Pages, Netlify, etc.)

## Struktur
- `index.html` – Hjemmeside
- `about.html` – Om Live
- `services.html` – Tjenester
- `contact.html` – Kontakt
- `css/style.css` – Hovedstiler
- `css/typography.css` – Skrifttyper
- `js/main.js` – Interaktivitet
- `images/` – Bilder (legges til senere)

## Design
- Fargepalett: Myke grønne toner, varme nøytrale, krem-bakgrunn
- Typography: Seriff + sans-serif kombinasjon
- Layout: Romslig, rolig, profesjonell
